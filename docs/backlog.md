# Example evolution backlog

1. **P1 — Anchors and structured decision records.** Validate Markdown anchors and move decision details from one-line records only when a real project needs richer machine-readable fields.
2. **P1 — Executed-test adapters.** Keep executed evidence in versioned files; add adapters only for CI systems that can provide immutable run URLs and artifacts.
3. **P2 — Graph views.** Generate a read-only traceability graph after the current flat validation proves insufficient for review.
4. **P2 — Configurable secret policy.** Allow projects to add narrow patterns without weakening the built-in checks or logging matches.
